# Clarifications for interpreting this experiment

- Both new models are LoRA-only continued SFT from the published checkpoint. Vision, MDP, projector and original language weights remain frozen. No SCST, feature-matching module, real3D data or LocateAnything is introduced in this round.
- The192 replay/positive records are inherited:128 official-caption replay records,44 prior assistant-reviewed/corrected records and20 repeats of those corrections. They are172 unique image pairs before augmentation/repetition. Some replay labels describe nuisance-only differences; positive here names the replay category, not guaranteed physical object change.
- Therefore “no generated model captions as ground truth” in the plan means no predictions from the new evaluated models were used as pseudo-labels. It does not mean every inherited target was independently human-annotated. Prior assistant corrections are a label-quality limitation.
- Each arm has512 records and1024 sample presentations across2 epochs,128 optimizer updates. Effective learning-rate budget, number of steps, data diversity and GPU time are different quantities; do not equate128 updates with128 epochs or more independent scenes.
- Exact decoded-RGB separation excludes958 hashes from the selected prior training/diagnostic inputs, not all images in previous full-test inference. The official test had already been evaluated previously. These are new selected pairs for this check, not a pristine independent test.
- Natural minimum facts and synthetic truth were locked before initial predictions. A dependent positive-plus-geometry supplement was added after the initial base/old-adapter check but before new-arm predictions. Selection policy timestamps/hashes are saved.
- Main96-case comparisons use two sequential A10-family containers: base/old together, new control/revised together. Stress64 generations use all4 models sequentially on one A10-family container. Same decoding is not a claim that all main predictions came from one physical GPU.
- All qualitative scores are assistant assessments, with uncertain cases explicitly retained. Model names were hidden during annotation; wording can still reveal training style, so this is not independent human-blind validation.
- The secondary brightness-acknowledgement derivation was corrected after decoding. Original assessments and an audit prove physical/light/geometry error flags, fact hits and unsupported-claim judgments did not change. It does not affect any gate.
- The saved LoRA weights are inference checkpoints. This run did not save a complete optimizer/scheduler/RNG resume state. Moving them to another compatible inference setup does not require training again, but exact training resume is a different operation.
