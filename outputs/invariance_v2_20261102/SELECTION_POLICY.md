# Selection rule recorded before new-arm captions

Both new arms are reported. Original gate is unchanged: fewer synthetic unsupported-claim cases than base, no reduction in natural fact hits in either domain, no additional natural unsupported-pair count.

If both qualify, prefer fewer unsupported-claim cases on the48 geometry cases; then fewer on all80 synthetic cases; then more natural fact hits. Ties are reported as ties, not resolved by looking at full test. Passing the pilot is only eligibility for broad evaluation, never evidence of a full-benchmark gain.

The positive-plus-geometry supplement is a safety check: candidate fact hits must be at least base in EACH domain and its unsupported-pair count must not exceed base. Otherwise promotion is blocked even if the original narrow gate passes. Report its dependent nature and the fact it was added after the initial base/old-adapter check.

Old mixed is not eligible for another full run merely because it passes this small gate: it has already failed full1570. New candidates that fail the gate do not get full1570 runs merely to use credit. Remaining credit is retained when no justified candidate remains.

If a candidate qualifies, evaluate with unchanged official prompts and decoding, report every metric and both domains, keep baseline as the default until broad evidence supports changing it. No claim that the previous baseline and a new run are a perfectly controlled same-device causal estimate without a matched rerun.
